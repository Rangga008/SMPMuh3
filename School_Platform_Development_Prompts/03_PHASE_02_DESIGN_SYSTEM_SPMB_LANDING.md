# PHASE 02 — DESIGN SYSTEM + SPMB PUBLIC LANDING PAGE

## Objective
Create a polished public SPMB website that can be shown to SMP Muhammadiyah 3 Kota Bandung.

## Important
Do not build the complete SPMB backend yet. This phase is primarily the public-facing product experience.

## Design
Modern Indonesian private-school admission platform:
- professional
- trustworthy
- warm
- parent-friendly
- mobile-first
- fast
- accessible
- restrained animation
- no generic SaaS appearance
- no excessive glassmorphism

## Sections
1. Header/navigation
2. Hero
3. School introduction
4. SPMB overview
5. School advantages
6. Admission pathways
7. Timeline
8. Requirements
9. Registration CTA
10. Payment information
11. FAQ
12. Contact
13. Footer

## No Invented Facts
Do not invent achievements, accreditation, facilities, statistics, address, phone, fees, dates or official slogans. Use configuration/placeholders until verified.

## Configurable SPMB Data
- academic year
- registration status
- period
- pathways
- requirements
- timeline
- FAQ
- payment information
- contact
- CTA

## UX
Primary CTAs:
- Daftar Sekarang
- Cek Status Pendaftaran

Design for:
360, 390, 430, 768, 1024, 1440px.

## SEO
Implement:
- title
- description
- Open Graph
- semantic headings
- sitemap
- robots
- structured data where appropriate

## Accessibility
- semantic HTML
- keyboard navigation
- focus states
- accessible accordion
- alt text
- contrast
- reduced motion

## Performance
- Next Image
- optimized fonts
- minimal client components
- lazy loading
- minimal JavaScript

## Done When
A school representative can understand what the school is, what SPMB is, how to register, requirements, timeline, payment concept and contact path.
